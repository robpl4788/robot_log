# Silvanus

A logging and analysis platform designed for lightweight robots and embedded systems developed in flutter.

Currently this is minimally working, reading js files over a serial port (at least on my windows machine), and plotting results to a graph.

## Aims to:

### Read:
 - CSV
 - Serial Printouts
 - Custom log files

### Plot
 - Line
 - Statistics
 - 2d and 3d poses in custom environments

 ## Name:
 Silvanus is roman god of forests, logging happens in forests.
